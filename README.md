# FisioCardioRespira

Blog académico sobre alteraciones cardiovasculares y respiratorias, con enfoque educativo y de fisioterapia.

## Archivos
- `index.html`: estructura y contenido principal del sitio.
- `styles.css`: diseño adaptable a móviles, tabletas y computadoras.
- `script.js`: catálogo de 17 temas, buscador, filtros y ventanas de detalle.

## Publicar en GitHub Pages
1. Descomprime el archivo ZIP.
2. Entra en el repositorio de GitHub y selecciona **Add file > Upload files**.
3. Sube los cuatro archivos y confirma los cambios en la rama `main`.
4. En **Settings > Pages**, selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
5. Guarda y espera a que termine la publicación. Abre la dirección que GitHub Pages muestre en esa sección.

## Personalización
Puedes modificar textos en `script.js`, estilos en `styles.css` y secciones en `index.html`.

## Nota académica
El material es informativo y no sustituye la evaluación, el diagnóstico ni las indicaciones de profesionales sanitarios. Revisa y complementa los contenidos con bibliografía y guías clínicas actualizadas antes de su entrega académica.
